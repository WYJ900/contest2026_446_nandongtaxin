# VelaRide 安卓伴侣（0.1.4）

手机通过 BLE 直接连接手表，不依赖电脑或云端服务。首版运行于安卓 8.0
及以上，前台使用；当前不包含 AI 对话或蓝牙音频传输。

## 已实现

- 只搜索 VelaRide 的 FFF0 服务，用户选择手表；记住设备供下次重连。
- 通知订阅完成后才显示连接就绪；自动检查通信、校准时间、读取状态。
- 同步最近一次已结束的骑行，并累积保存在手机私有存储，断线仍可查看历史和详情。
- 自动迁入 0.1.1 的最近记录；按手表地址、记录序号和摘要去重，重复同步保留首次同步时间与备注。
- 查看累计时长、分享单条文字摘要，或通过系统文件选择器导出全部记录为 UTF-8 CSV。
- 备注收到手表成功回复后，保留在手机对应历史中。文件原子替换、CRC 校验；读取损坏文件时保留原文件并报错。
- 匹配支持 GPS 生命周期的新固件时，用户开启定位后约每 5 秒回传真实手机 GPS 速度与本次累计距离。
  进入后台、关闭定位或断线时停止采集；停止和断线后清除表端旧定位值。
- 将用户输入的简短备注回传至相同序号的骑行，避免覆盖新骑行记录。
- 单通道顺序请求，18 字节 ATT 分片；完整 UTF-8 行组装，有限超时，
  连接切换后拒绝旧任务，避免把迟到回复当成新操作结果。

App 没有网络、麦克风、后台位置或外部存储权限，不把手机麦克风作为
板载录音替代。后续语音方案见 [手机与手表接入计划](../../docs/PHONE_COMPANION_20261026.md)。

## 安装与使用

安装产物：工作区 `exports/mobile/VelaRide-0.1.4-debug.apk`。
这是开发签名 APK，无需登录。手机系统可能要求允许当前文件来源安装应用。

1. 给手表供电，打开 App，允许“附近设备”，点击“连接手表”并选择 VelaRide。
2. 等待“数据通道就绪”。自动校时后可刷新状态、同步骑行。
3. 骑行记录由手表正常开始/结束产生。无已结束记录时 App 不填入样例。
4. 定位同步另需精确位置权限与系统 GPS，建议在室外验证。
   本次距离从每次开启定位时重新累计；只在 App 前台运行，不提供地图轨迹。
5. 备注在结束骑行并同步最新记录后发送。手表中文字显示仍受固件字库范围影响。
6. “我的骑行历史”中查看详情、分享摘要或导出 CSV。导出后可用手机文件应用分享该文件。
   安装新版可覆盖旧版（包名和开发签名相同、版本号递增）；不要先卸载，否则手机私有记录会被清除。

手表目前只提供最近一条已结束记录，所以需要在下一条骑行结束前同步上一条；App 不能找回已被手表覆盖的记录。
历史中的时间是手机同步时间，**不是骑行日期**；没有生成速度、距离、GPS 轨迹或示例记录。
地址不同的手表分开保留；同地址同序号但摘要不同也分开保留。若手表重置后产生完全相同的序号与摘要，
当前协议无法区分，仍会视为重复记录。手机最多保留 5000 条，达到上限明确报错，不自动删除旧记录。

0.1.3 沿用 0.1.1 的新旧协议兼容方式；GPS 配套候选固件为 `00e511f1…`，
由夜骑候选 `a9bd9f25…` 定向移植，仅改两个骑行/BLE 源文件。
握手中仅对 `phone_clear` 的 `unknown_cmd` 回复禁用 GPS 扩展，继续基础同步；
超时、断线及其他错误仍按失败处理。定位按钮会明确提示等待手表升级。
`00e511f1…` 支持定位清除、断线失效、重新订阅清除和接收 15 秒后过期；旧固件仍需升级后才能开启定位。
`00e511f1…` 遗漏了 GPS 显示补丁；请使用界面修正版 `bf903878…`。
路径：表盘短按侧键 → 设置（齿轮）→ 上滑 → **连接与校时**；菜单蓝牙图标“连接”也可进入。
页面显示速度和本次定位累计距离，无有效数据时显示 `--`。
新版骑行统计固件 `9041c538…` 另将 GPS 绑定到手表开始/暂停/结束：结束记录中保存距离、
GPS 有效采样均速、最高速度和采样时长，App 0.1.4 的最近记录、历史、分享和 CSV 均可读取。
旧记录无定位统计时显示缺失，不补成零；暂无地图轨迹。
App 0.1.3 拒绝旧定位点、乱序点和明显跳点；长时间失去信号后不把定位空档跨接为距离。
手机与手表均有过期保护；定位必须保持 App 前台，锁屏或切到其他应用会停止。

v18 的手机定位扩展仍是待分拆移植的历史实现，**不要为了手机定位刷回 v18/v19**。
当前设备镜像及验证边界见 [夜骑交接](../../docs/HANDOFF_NIGHT_20261028.md)，App 最新进度见
[GPS 接续](../../docs/HANDOFF_PHONE_GPS_20261101.md)。

## 构建

仅使用 JDK 与官方 Android SDK，无第三方 App 依赖，也无需 Gradle 下载依赖。

```powershell
.\build.ps1 -SdkRoot '<Android SDK 目录>' -JavaHome '<JDK 17+ 目录>'
```

需要 `platforms;android-35`、`build-tools;35.0.0`。在当前工作区，工具安装于
`.local-tools/android-sdk`，脚本会自动查找。脚本生成新的 `.build/run-*`，
先运行纯 Java 协议检查，再编译、DEX 转换、对齐和开发签名，最后核验 APK。
开发签名私钥保存在被忽略的 `.build/debug.keystore`；不是发布签名。
