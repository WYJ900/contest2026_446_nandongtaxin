# GPS 页面遗漏修正（2026-11-01）

> 后续用户确认“123是对的”：基本手机 GPS 数值、停止清除及原手表操作正常。
> 该版已冻结为后续骑行统计的父基线，见 [最新交接](HANDOFF_RIDE_GPS_20261101.md)。

用户询问“手表这没看到你让我找的东西”。实际入口为：
**表盘 → 短按侧键打开菜单 → 设置（齿轮）→ 上滑列表 → 连接与校时**。
菜单蓝色蓝牙图标“连接”也通向该页。屏幕熄灭时先唤醒，再在表盘短按侧键。

排查发现上一版 `00e511f1…` 的通信层已支持 GPS，但实际 WSL 固件树仍使用旧连接页，
完全没有 GPS 数值显示。规范仓本来有显示代码，之前仅测试规范仓，未验证构建树，导致错误宣称显示已接通。
这不是用户操作问题。先前 BLE 模拟输入/超时/重连的结果仍有效，但不能作为界面显示完成的证据。

## 修正范围

- 从上一版只改 `velaride_sport_ui.c` 的连接信息分支；配置、驱动和其他应用源码完全相同。
- GPS 速度、公里数放在连接状态下方，无数据时明确显示 `GPS -- km/h / -- km`。
- 页面提示在手机 App 开启定位并保持前台。现有 250ms 信息定时器负责刷新。
- App 0.1.3 不变，无需再安装新 APK。
