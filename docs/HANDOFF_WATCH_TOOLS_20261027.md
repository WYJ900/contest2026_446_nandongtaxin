## 使用

菜单新增“倒计时”，蜂窝与列表菜单均可进入。

- 1、5、10、25 分钟预设，或按 `-1` / `+1` 调整到 1–180 分钟。
- 开始、暂停、继续、取消，到时可再次开始。
- 退出页面、进入其他页面或熄屏不取消计时。
- 到时亮屏显示横幅，并写入通知中心；勿扰时仅保留通知。
- **本版静音，没有调用录音/放音诊断命令。** 运行状态不跨重启保存。
- 使用单调毫秒计时，独立于骑行前的三秒倒数和秒表；修改日期不会改变剩余时间。
