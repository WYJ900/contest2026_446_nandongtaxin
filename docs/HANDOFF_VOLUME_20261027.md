## 使用

菜单“声音”，或“设置 → 声音与提示”：

1. 选择“有声”。
2. 拖动 **0–100% 滑块**，或点击/长按 **-5 / +5**。
3. 点击“试听”。播放期间也可继续调节，不会重新开始音频。

100% 等于用户此前认可的最大响度，没有扩大上限。
音量为 0 时数字输出静音，仍在播放时间范围内调高可以恢复。
“静音”开关或“停止声音”则会结束当前播放并关闭功放。
模式语音、提醒铃声仍可分别开关；勿扰继续抑制声音。

设置会后台合并保存，避免拖动每一步都写 Flash。
界面显示“正在保存”时，最终值还在等待写入；播放中调节会先实时生效，随后保存。
旧 VRS1 的“标准”迁移到 100%，“柔和”迁移到 35%；新 VRS2 保存任意百分比。

自动测试后曾恢复为 **静音、音量 100%**；用户随后选择了 **有声、100%**，已保留。
闹钟恢复 **07:00 关闭**，原第 11 条骑行保留。
手表时间已通过电脑 BLE 重新校准。无需手机 App。
