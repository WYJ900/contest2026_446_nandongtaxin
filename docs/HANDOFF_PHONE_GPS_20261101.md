## 本轮实现

- App 0.1.3（versionCode 4）：保持前台定位，每约 5 秒通过原 BLE 控制通道发送速度与累计距离。
  新增纯 Java 定位输入检查，拒绝超龄、乱序、重复、非有限值、不合格精度和明显跳点。
  定位中断超过 15 秒不累计空档距离；静止时保持有效零速度。
- GPS 启停使用独立世代号，旧任务不能在重开定位后继续发送；停止、断线、切后台均停采集。
  UI 显示过期状态，清除表端旧值；回到前台需要主动开启。
- 手表加入 `phone_clear`、`ride_status` 定位回读、断线/通知订阅重置；速度和距离用互斥锁成对访问。
  数据在最后接收 15 秒后失效，使用单调时钟，校时不会延长有效期。
- 旧 `phone_data` 数值限制补全为有限非负速度 ≤200 km/h、距离 ≤100000 km；App 的跳点上限为 150 km/h。
- 现有“连接”页显示 GPS 速度与距离。未增加地图、轨迹、后台骑行或骑行记录中的 GPS 字段。
  距离从每次开启定位重新累计，是手机定位估计值，需要室外实测准确性。
