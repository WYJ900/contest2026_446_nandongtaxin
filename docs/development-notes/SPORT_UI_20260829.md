## 已落地范围

- 主界面保留五个表盘、左右滑动切换和五表盘常驻 PSRAM 转场快照。

## 待完成人工验收

1. 左右滑动确认五个表盘都存在。
2. KEY2 单击进入蜂窝，确认中心放大和自由二维拖动。
3. 返回表盘，KEY2 快速双击进入运动流程。
4. 完成类型、目标、区间和组数选择，进入运动中。
5. 验证暂停、继续、退出确认和返回原表盘。
6. 在持续滑动时用 `tools/fps.ps1` 采集 `VELARIDE_PERF`；目标有效刷新率至少 25–30 Hz。

静止或未形成有效手势时不会产生性能行，不能把空采样当作 FPS 结果。

## 骑行核心与持久化

已接入 `velaride_ride_session.c`，提供开始、暂停、继续、结束、250 ms LSM6DSL 采样、运动/静止分类、冲击后静止、长时间静止和休息提醒。结束骑行时会保存最近一条记录并进入本地复盘页。

记录存储在 `/dev/config0` 对应的独立 NOR Flash 配置区，使用 NVS/KVDB 和 CRC32 校验。2026-08-29 真机验收已通过：同一测试记录在立即读取、RTS 复位、重新烧录固件后三次读取一致。诊断命令如下：

```text
velaride persist-probe   # 底层配置读写探针
velaride persist-write   # 写入固定测试记录
velaride persist-read    # 读取并打印最近记录
velaride persist-format  # 危险：清空配置区，仅维修时使用
```

普通烧录不会覆盖持久化配置区；构建脚本也会在固件达到 `0x990000` 字节边界时拒绝产出。真实 UI 的“开始 → 暂停/继续 → 结束 → 复盘 → 重启后加载”仍需人工完成最后一轮视觉与交互验收。

修正版额外解决：退出确认回调访问已删除事件对象的黑屏风险；室内骑行/自由训练标题写死为户外骑行；点“继续”后计时、里程和暂停状态被重置。

## 中文界面

运动流程已全部改为简体中文。使用 Noto Sans SC 生成 20 px、24 px 的按需子集字库，数字和单位通过 Montserrat fallback 显示。字库覆盖源码实际使用的全部汉字，构建前缺字扫描结果为“无”。

中文候选构建结果：Flash 9,353,512 B（55.75%），SRAM 441,132 B（84.14%）。2026-08-29 11:43 冷启动实测 LCD、触摸、EPIC 和快照均正常，首张快照 96 ms；中文视觉效果待人工确认。

首次中文候选真机显示为占位框。根因不是 UTF-8 或缺字，而是 `lv_font_conv` 默认生成 RLE 压缩字形（`bitmap_format=1`），当前配置同时关闭了 `LV_USE_FONT_COMPRESSED`，LVGL 无法解码字形位图。未改全局渲染配置，改为以 `--no-compress` 重新生成两份子集字库（`bitmap_format=0`）。修正版为 `backup/nuttx_sport_ui_cn_glyphfix_20260829_114941.bin`，构建结果 Flash 9,364,496 B（55.82%）、SRAM 441,132 B（84.14%）；冷启动正常，中文显示待人工复核。

字形修正版真机复核后，配置页等中文正常，骑行计时页动态指标仍为框。根因是该指标标签仍显式绑定 `lv_font_montserrat_20`。已局部切换为 `velaride_font_cn_20` 并重新烧录，固件备份命名为 `nuttx_sport_ui_cn_metricfix_*.bin`；Flash/SRAM 数值不变，冷启动正常。

为改善 AMOLED 上中文偏细的问题，将 Noto Sans SC 可变字体固定为 `wght=600`，重新生成 20/24 px 未压缩子集字库。未使用有再分发限制的苹方。当前固件为 `backup/nuttx_sport_ui_cn_semibold600_20260829_132706.bin`，构建结果 Flash 9,367,312 B（55.83%）、SRAM 441,132 B（84.14%）；冷启动正常，首张快照 98 ms。
