# 已知限制

## 长时间运行

在 `velaride-watch-product-20261010.bin` 上发现约 71 分钟后系统微秒换算回绕，UI 和采样周期任务会停摆。
当前 `velaride-timer-fix-20261010.bin` 已修复，源码与实机加速跨界验证通过，并恢复正常起点安装。
自然运行数小时的整机耐久观察仍待完成；该故障不等同于解释全部历史面板黑屏原因。
证据见 [计时修复记录](TIMER_STABILITY_20261010.md)。

地磁采样、校准与方向预览已实现；实物校准、安装方向与北向仍待核对，未实现倾斜补偿，不能作为已验收的导航指南针。马达、喇叭安装情况待确认。

## BLE

2026-10-09 已修复 HCI 共享内存缓存、堆覆盖 mailbox、回调发送及断线广播问题。
`rcS` 自动启动 BLE；真实 GATT 收发与连续三次重连通过。尚未覆盖长期户外运行、
大量不同电脑蓝牙适配器及低功耗恢复，详细证据见 `HARDWARE_UPGRADE_20261009.md`。

## 显示

EPIC 加速版本在链路测试完成后复发黑屏，唤醒和强制重绘无效。当前关闭
`CONFIG_LV_USE_DRAW_EPIC`，使用 CPU 绘制；烧录后表盘、滑动和触摸恢复，但第一次复位再次黑屏。
关闭 EPIC 未解决故障，根因仍未确定。长期显示稳定性及 CPU 绘制的功耗影响尚未验证。

后续已确认黑屏时面板配置丢失，并加入实际状态检查、独立屏幕恢复和完整重绘，
保留共用供电。中间版两次复位后用户确认画面和交互正常；最新证据和验证边界见
[显示恢复记录](DISPLAY_RECOVERY_20261009.md)。

## USB 串口

CH340 与复位线耦合，历史串口联调还混有显示缓存与 Flash XIP 竞态问题。当前
诊断脚本保持 DTR/RTS 关闭，显式 `--reset` 才复位。网页串口接口默认关闭，日常
数据链路使用 BLE；串口诊断可能中断用户操作。

## Web 数据录入

网页首次连接需用户在浏览器设备选择器中选择 VelaRide。连接后可读取当前状态、
最近保存记录并回传复盘；手工录入作为备用方式。当前没有真实 GPS 输入，未提供
的距离按“未记录”交给模型，不推算速度和距离。

## AI Agent

`ride-safety` Skill、工具白名单和设备命令已经实现。设备端确定性规则始终可用；
完整在线 Agent 自动控制链路不作为本次稳定演示内容。

## 字体

19 px / 2 bpp 正文字库包含 3,770 个中文及标点字形，ASCII 使用原有字体。网关字表与固件
同源生成。字库外文本先由同一 AI 在总超时内改写一次，成功后网页与手表显示同一
份最终正文；改写失败才使用明确标记的规则短版。手表文本最多
260 字节，按 UTF-8 字符边界裁剪。手表页使用通用“骑行复盘”标题。
显示恢复基线的配置区余量为 50,640 字节；新产品候选移除表盘位图后余量为 767,532 字节。
后续增加代码或字体仍必须通过大小检查。

## 提交整理后的构建

本轮使用已有 Ubuntu-22.04 WSL 构建树增量编译并多次烧录验证，补齐 LVGL、ZBlue
和 external 集成补丁。所有补丁对当前工作区的反向检查通过；尚未在全新下载的
工作区执行全量构建。旧驱动仍有全文件 checkpatch 风格问题及已有链接警告。

## AI 接口

三种标准兼容协议通过模拟测试，并通过用户配置的 Anthropic 兼容中转站完成真实
调用。具体中转站的模型权限、额度、延迟和返回格式仍需实测；配置徽标仅表示
凭据和参数存在，实际结果来源与失败降级会单独显示。不提供原生 Gemini/Ollama
专属协议；若服务支持上述兼容格式，可使用兼容入口。
