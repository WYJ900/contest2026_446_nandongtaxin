# 已知限制

## BLE

FFF0/FFF1/FFF2 GATT 协议、JSON 分片和设备命令已经实现，但 SF32LB52 LCPU HCI
TX 时序仍会阻塞。`rcS` 不自动启动 `velaride_ble`，稳定演示不使用 BLE。

## USB 串口

CH340 与复位线耦合。长连接和短连接都出现过黑屏或卡死，因此视频录制和日常演示
不访问 COM5。串口桥接代码只保留用于开发诊断。

## Web 数据录入

当前 Web 网关不会自动读取手表。用户在手表结束骑行后，照本地复盘页手工填写
真实数据，再调用 MiMo。网页不应被描述为已自动连接设备。

## AI Agent

`ride-safety` Skill、工具白名单和设备命令已经实现。设备端确定性规则始终可用；
完整在线 Agent 自动控制链路不作为本次稳定演示内容。

## 字体

手表固件使用按需中文字形子集。网页保留 MiMo 原文；当原文包含字库外字符时，
手表版本使用字体安全的短复盘。

## 提交整理后的构建

本提交包保存已有真机验证固件、源码、patch 和 overlay。本轮整理没有重新执行完整
openvela build，提交前建议在干净工作区做一次最终构建并记录产物哈希。
