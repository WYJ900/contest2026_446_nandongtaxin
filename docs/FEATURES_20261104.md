# 骑行安全助手新增功能使用说明

当前安装固件：`artifacts/install-stage-20261104/firmware.bin`（`8027be11…`），配套安卓 `exports/mobile/VelaRide-0.2.0-debug.apk`。
固件已校验写入，5次重启和BLE检查通过；用户确认基础操作及新设置正常。真实手机GPS、GPX、AI、TF录音尚待各自验证。

| 功能 | 使用路径 | 实现边界 |
| --- | --- | --- |
| 异常安全确认 | 冲击后持续静止触发 → 我没事/暂停休息/需要帮助 | 超时仍保留确认，求助只记录意向，没有发送短信或电话 |
| 离线历史 | 菜单 → 骑行记录 → 选择历史 | 手表保留最近 16 条；手机自动/手动补传，断线已完成部分保留，重复同步去重 |
| 有依据的复盘 | 手表骑后页；App → 历史详情 → 骑行复盘 | 离线规则明确标注；在线需自行配置 HTTPS 网关，结果来源和降级明确显示 |
| 休息/补水动作 | 骑行 → 运动类型 → 骑行设置 | 点击切换间隔，提醒后可执行、稍后 5 分钟或忽略；选择进入记录/CSV/复盘 |
| 停车/继续建议 | 同一骑行设置内开启 | 根据有效 GPS 与六轴建议，必须用户确认才改变计时，不是自动刹车或可靠摔车判断 |
| 距离目标和分段 | 骑前设置距离/自动分段；控制页点分段 | 依赖有效 GPS；可继续骑行，自动标记有采样边界误差；保存分段总数，不保存完整每圈时间线 |
| 路线点指引 | App 导入 GPX → 开启前台定位 → 手表骑行朝向页 | 路线几何方向、距下一点直线距离和偏离提示；15 秒失效；没有道路重规划 |
| 停车语音标记 | 手表控制页暂停 → 语音标记 → 录制 3 秒；App 同步/试听/关联 | 需 FAT TF 卡；板载麦克风；固定短录音，手动选择真实骑行关联，不上传或自动识别 |

## 在线复盘

App 的复盘页可以保存完整 HTTPS `/api/ride/review` 地址。服务端继续复用团队仓 `web-gateway/` 的 AI 接口和安全启动器；模型 Key 在服务端配置，不填写到 App 或聊天。
没有服务时仍可离线查看本地复盘。GPS 缺失、旧记录无安全结果、服务端规则降级均明确标识。
回传前会核对手表最新记录的完整统计身份，不把历史建议覆盖到另一条骑行。

## GPX

使用 UTF-8 的单条路线或单段轨迹，2–2000 个点，最多 512 KB。导入文件复制到 App 私有目录，不改用户原文件。
文件选择器会让原前台定位停止，返回后重新开启。小于约 25 米的密集点会合并；到达、偏离和转向提示需要室外实际验证。
手机锁屏或切后台仍停止定位，后台持续定位按用户原安排另做验证与开发。

## 语音

TF 必须实际挂载为 FAT；只有 `/data/tf` 空目录不算就绪。录音时保持手表暂停。
App“同步手表最近录音”不会启动麦克风；仅复制已经保存的文件。同步中保持暂停，断线可重新同步。
手机校验成功后才能试听，点“将录音关联到骑行”选择相同手表的实际记录；录制时的待结束编号仅作提示。

## 验收范围

所有新功能通过构建、实际阶段 LVGL 和主机适配器测试；综合版基础显示/触摸/滑动/侧键/抬腕和新设置已获用户确认，新旧骑行记录已真机读回。
GPS精度、各类提醒实际触发、完整手机补传和TF录音/试听仍待实测，不能将基础确认扩大为全部新功能已验收。
没有用软件截图、模拟 GPS/PCM、ACK 或构建通过代替实际触摸、抬腕、定位、听感和 Flash 掉电保存。
当前实机界面为原生 NuttX/LVGL；快应用赛道要求的快应用核心流程与模拟器交付仍需独立对齐，不能因为有旧 `.ux` 工程就视作完成。
