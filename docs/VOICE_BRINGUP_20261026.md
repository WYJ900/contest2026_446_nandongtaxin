目标是保留 VelaRide，由手机中转联网，先安卓，再评估 iPhone。
当前先完成板载麦克风与喇叭的短时半双工验证；尚未接通语音识别、
大模型和语音合成，也没有完成手机蓝牙音频传输。

## 已验证：板载麦克风到电脑

- v14 于 2026-10-26 经 USB 重新插拔后成功烧录并校验。
- 16 kHz、16-bit、单声道，每次录音 1–5 秒，录完即关闭 ADC 和麦克风偏置。
- ADC0 DMA 请求号为 39；采集前后显式维护 DMA 缓存。
- 5 秒采集 DMA 用时 5005 ms，80,000 样本；串口导出采用连续偏移与

- 第一次用户没赶上说话，文件只有启动脉冲与低电平背景。
- 第二次用户说话，导出 `exports/voice/mic-speech-20261026.wav`，
  校验值 `6181daab`，无满幅削波。电脑播放放大试听版后，用户确认可听清。
- 原始文件开头约 150 ms 有模拟通路启动瞬态，峰值约 23,869；
  该峰值不代表人声音量。后续 v15 增加 200 ms 预采集并丢弃。

## 复现

在固件就绪、NSH 可用、BLE 已就绪且未连接手机时运行：

```powershell
py -3 tools/mic_capture.py --port COM5 --seconds 5 --countdown 5 --playback --output exports/voice/mic-loopback.wav
```

该命令使用一条串口连接：暂停广播、倒计时、录音、校验并保存 WAV、
板端回放一次、确认功放关闭、恢复广播。不开机自动播放，不运行音乐循环。
`--playback` 默认关闭；不带此参数只录音导出。录音文件可能随板子复位丢失，
电脑导出的 WAV 不受影响。

对已确认的录音做独立回放（v16 及以上），跳过 v14 的 200 ms 启动瞬态：

```powershell
py -3 tools/voice_upload.py exports/voice/mic-speech-20261026.wav --skip-ms 200 --playback --log backup/speaker-20261025/known-voice-upload.json
```
