# 骑前设置、提醒动作、停车建议和目标分段（2026-11-03）

本阶段继续 `55b7896` 复盘阶段。原 GPS 设备未连接/刷写，没有播放或录音。

已实现：

- 骑行 → 选择运动 → 骑行设置：切换休息/补水间隔、距离目标、自动分段距离和停车建议。独立 CRC 属性保存，骑行中不接受修改；默认休息 45 分钟，其余关闭。
- 休息与补水提醒支持执行/延后 5 分钟/忽略，选择进入结束记录和复盘输入。休息按累计运动秒，补水按未暂停会话秒；提醒次数不等于实际休息/补水次数。补水“已补水”仅表示用户确认。
- 停车建议需用户开启；静止且有效 GPS 低速时建议暂停，暂停中六轴和有效 GPS 持续检测到移动时建议继续。必须确认才改变计时，拒绝把传感器结果直接变成自动暂停/继续。
- 距离目标需要本次有效 GPS 累计，达到后提示且可继续；时间和距离目标分别只提示一次。数据页显示距离剩余，无采样显示缺失。
- 控制页可手动分段，记录最近标记间隔时长；可选按约定距离自动标记。自动标记在收到 GPS 采样后触发，距离可略大于设置值，不对边界插值补造精确圈速。结束记录保存分段数，不保存每段完整时间线。
- 安卓 0.1.8 最近/历史/分享/CSV 显示和保留目标、分段及提醒选择，在线复盘也接收这些实际字段。新旧记录同步不抹除已知扩展信息。

记录升级 V4，冻结 V1/V2/V3 原始布局只读兼容；旧记录新字段显示缺失。原始对象 120 字节，KVDB 编码 240 字节，小于 255 字节属性上限。手机 VRH4 只读兼容 VRH1/2/3，保存时升级。保存新格式后不要随意降级旧固件/APK，先同步导出。
