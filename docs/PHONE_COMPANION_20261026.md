## 目前采用的结构

手表继续运行 VelaRide。安卓 App 通过 BLE FFF0 直接连接手表，FFF1 接收
通知，FFF2 分片写入 JSON 行。时间、骑行和定位都在手机与手表之间传输，
不经过电脑。电脑仅用于当前开发、刷机和回归验证。

## 第二阶段：蓝牙音频

复用已验收的板载麦克风、完整缓冲播放和峰值限制，做短时半双工：

1. App 发起板载录音，结束后按长度、偏移和校验传到手机。
2. 手机可本地试听该录音，也能传回短语音让手表播放一次。
3. 采用可协商 MTU、二进制分片、回执和流控，先验证蓝牙连接期间的音频
   清晰度与吞吐。现有保守 18 字节 JSON 控制通道不直接承担低延迟长音频。
4. 连续录音、低延迟流式播放与后台保活按实测逐步扩展。

当前音频已通过的是“串口导出到电脑”和“已知录音传回板子播放”，
并非手机蓝牙音频已完成。听感证据及参数见
[板载语音验证](VOICE_BRINGUP_20261026.md)。
