## 使用

菜单新增“闹钟”。用“时 - / 时 + / 分 - / 分 +”设置时间，支持长按连续调整。
点击“保存并开启”后每天在该分钟提醒一次。“关闭闹钟”会保存关闭状态。
到时可点击“知道了”确认，但不会取消次日的提醒。

**这一版为静音亮屏提醒**：横幅和通知中心记录，遵守已有勿扰开关。
声音提醒尚未实现；不会把音频诊断命令当作正式闹钟放音服务。

时分和开关通过独立的 `persist.velaride.alarm` 键保存，并有格式/范围/CRC 校验。
保存由独立任务完成，避免阻塞 LVGL。
这块板断电后可能恢复旧的保存时间，因此每次重启后，已开启的闹钟会显示
“请先核对右上角时间”，点击“确认时间并开启”后才开始提醒。
不能把这个确认机制当作 RTC 自动校准；时间不正确时仍需校时。

在目标分钟内开启会从次日生效；轮询不会重复提醒，时钟回拨不会重放当天已提醒的闹钟。
跳过了目标分钟不会补发过期提醒。

测试结束已恢复为 **07:00、关闭状态**；倒计时为空闲的 5 分钟预设。
已通过电脑 BLE 校准当前手表时间，手机仍未接入。
