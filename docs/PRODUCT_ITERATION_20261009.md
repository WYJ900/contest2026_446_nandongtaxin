## 产品判断

先把已有触摸屏、六轴、按键、持久化与 BLE 用成完整的骑行助手。本轮的价值是让入口、目标、提醒和复盘都有可验证的结果；未接入的数据不伪造，也不把没有效果的设置放进主要流程。

源码发现的缺口包括：运动选择页时间固定为 14:54、距离/心率目标未执行、心率区间和组数没有业务作用、配置页缺少返回、菜单图标只移动不打开功能、长复盘缺少独立滚动区。

## 本轮范围

| 环节 | 产品行为 | 验收依据 |
| --- | --- | --- |
| 菜单 | 中文功能入口，点击直接进入骑行、记录、安全、连接、设备或帮助；可回表盘 | 每个入口有实际页面，按键与触摸可返回 |
| 出发 | 选择运动 → 开放/15/30/60 分钟目标 → 六轴与时间检查 → 可取消的三秒倒计时 | 取消倒计时不创建骑行、不覆盖旧记录 |
| 骑行 | 优先显示实际记录时长、运动/静止状态与暂停；时长目标排除暂停，达标后允许继续 | 暂停不推进目标；提示只出现一次，不自动结束 |
| 提醒 | 连续静止、冲击后短时静止、累计运动休息提醒；明确“我没事/暂停” | 累计静止不能误当连续静止；旧冲击不永久等待未来静止 |
| 结束 | 二次确认，记录统计与 AI 建议分开；文字区可滚动，按钮固定 | 长中文不遮挡完成按钮；无记录/无 AI/保存失败均有明确状态 |
| 时钟 | 所有页面使用实际系统时间；连接说明解释校时方式 | 不再出现固定 14:54；不声称断电后离线走时准确 |

## 当前实现与软件验证

- 七个中文菜单入口：骑行、记录、安全、表盘、连接、设备、帮助。纵向功能卡也可点击进入；单击功能键在页面内返回。
- 实现开放/15/30/60 分钟目标、就绪检查、可取消倒计时和一次达标提示；移除未实际执行的公里/心率/组数选项。
- 运动页突出真实记录时长、动作状态、运动/静止时长、暂停/冲击次数及目标进度。
- 复盘分为“记录”和“建议”，使用固定按钮与独立滚动区。标题不强制称为 AI，因为现有持久化正文没有保存生成来源元数据。
- 保存失败的记录在内存保留，返回后可重试；成功保存前不会直接开始另一条骑行。重启丢失未成功持久化数据的限制仍存在。
- 连续静止计数与累计静止分离；冲击后静止观察窗为 10 秒，避免旧冲击永久等待未来静止；冲击提醒保持到确认，不被低优先级提醒覆盖。
- 连接标记来自 BLE 实际回调，表示蓝牙连接，不能等同于网页通知通道或云端 AI 已就绪。
- 原有 NVS 记录结构与分区保持；目标只在当前骑行会话生效，当前历史记录不存目标和运动类型。
