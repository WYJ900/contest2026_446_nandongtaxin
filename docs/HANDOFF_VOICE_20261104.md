# 停车语音标记与综合候选（2026-11-04）

继续路线阶段 `7657a38`。此综合候选包含之前全部新增功能，手表仍保持原 GPS 版，没有设备操作或实物录音/放音。

## 本轮实现

- 骑行控制页新增语音标记。先手动暂停，明确点击后固定录制 3 秒；录制期间侧键等待完成，不会启动连续录音或自动播放。
- 使用原样 `mic_test_main` 及共享音频锁，复用已验收板载麦克风，不更改 ADC/DMA/时钟/引脚/供电或音频驱动。另加应用层后台线程与 WAV 保存，启动时不启用硬件。
- 必须实际挂载 FAT TF 卡，保存到 `/data/tf/MEMOS/Mxxxxxxx.WAV`（8.3 文件名）。没有卡、空间/文件/音频错误会报错。独占创建文件，不覆盖已有或未完成文件，失败只清理本次新建文件。
- WAV 包含 16 kHz/16-bit/单声道 PCM 和自定义 `vrid` 块，记录当时骑行编号提示和“尚未结束”标志。编号提示不是已确认关联，重启后不会按重复编号猜测归属。
- BLE 只读录音清单、文件信息/CRC 和有界分片，不提供远程启动录音命令。
- 安卓 0.2.0 可同步最近完成的 3 秒录音，校验 ID、偏移、长度、CRC 和 WAV 头后原子保存。传输期间要求骑行暂停，定期检测继续骑行并中止，断线可重试。
- 手机只有点“试听”才播放，结束/切后台会释放播放器；不使用手机麦克风、不上传音频、不自动转写。
- 用户从相同手表的手机骑行历史中明确选择关联，历史详情可试听。关联使用稳定记录身份，后续补充 GPS/提醒字段不丢关联。
- GPX 文件保存增加原子写后的读回校验。
